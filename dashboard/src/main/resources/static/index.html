Лучшие места охоты

Опыт в час считается по снимкам опыта в окнах по 10 минут, где работал только бот (без ваших убийств); опыт и время окна делятся между клетками карты 2×2 по убийствам бота. Оценка = опыт в час со штрафом за смерти и упоры. Сравнивается только текущий уровень, клетки с малым временем не показываются.

Места упоров

Правила считает программа раз в 5 минут (смерти, зависшие бои, точки упора, клетки заметно хуже среднего по опыту в час); они действуют ограниченное время. Упоры сохраняются постоянно и не пропадают при перезагрузке страницы игры.

Разбор журнала бота

Нажмите «Сводка» — покажет, что чаще всего повторяется в журнале. «Копировать JSON» — компактные данные, которые можно отправить на разбор.
«Разбор моделью» — отправляет сводку в Ollama (модель из настроек analyzer.model), ответ приходит за 1–3 минуты.

Убийства «бот / я» определяются по тому, действовал ли бот последние 3 секунды или шла его задача. Данные вашей игры пишутся, пока запущен сервер wow-mcp.
