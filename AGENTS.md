# Правила для агента в этом проекте

- НИКОГДА не взаимодействуй с браузером и игрой напрямую: никаких скриптов к CDP
  (localhost:9222), Page.reload, навигации, кликов, ввода текста, Playwright-скриптов вне кода проекта.
- С игрой работай ТОЛЬКО через MCP-инструменты wow (get_state, go_to, ...).
- Не запускай ./deploy.sh, не убивай процессы (pkill), не трогай ~/.config/opencode.
- Если инструмент вернул ошибку "не в мире" / "экран входа" — НЕ повторяй вызов, сообщи игроку.
- Никогда не вводи и не запрашивай логины и пароли.
