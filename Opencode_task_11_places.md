## Часть 1. Места
Таблица `place(name text PK, zone int, x real, y real, note text, created_at)`. Имена — в нижнем регистре, без ё.
Заполнить сразу: `перекресток` (117; 51.8, 30.3), `лагерь таурахо` (117; 45.0, 58.9), `гарпии` (117; 40.9, 17.0).
Инструменты:
- `remember_place(name, note?)` — текущие координаты и зона под именем (перезаписать, если есть).
- `places()` — список мест текущей зоны с расстоянием до игрока.
- `go_place(name)` — бежать к месту (с боем по пути). Если место в другой зоне — ошибка «место в зоне N».
  Если есть маршрут (Часть 2), который начинается рядом с игроком (≤ 3 ед.) и кончается рядом с местом (≤ 3 ед.),
  в любом направлении — идти по нему; иначе прямо через go_to.

## Часть 2. Маршруты
- `record_stop(name?)` — необязательное имя: сохранить запись в `route`.
- `routes()` — список маршрутов: имя, зона, начало, конец, длина, число точек.
- `go_route(name, reverse=false)`: точки записи по порядку (или обратно), прореживание (шаг ≈ 1.5 ед.,
  но обязательно сохранить точки поворота > 25°), прохождение по очереди через существующий go_to/moveTo.
  Если обратное направление не указано — выбрать то, чей конец дальше от игрока (т.е. идти «от меня»).
  Начать с ближайшей к игроку точки маршрута (не бежать к началу, если стоим посередине).
  Застрял на точке — пропустить её и взять следующую; две подряд — стоп с причиной и координатами.
- Фоном, как остальные задачи; в get_state показывать: маршрут, точка N из M.

## Часть 3. Команды для AGENTS.md (добавить в таблицу)
| запомни место ИМЯ | `wow_remember_place` | сохранить текущее место |
| места куда / мои места | `wow_places` | список мест |
| иди к ИМЯ / иди в ИМЯ | `wow_go_place` | бежать к месту (по маршруту, если есть) |
| маршруты | `wow_routes` | список маршрутов |
| иди по маршруту ИМЯ | `wow_go_route` | пройти записанный маршрут |
| стоп запись ИМЯ | `wow_record_stop` name=ИМЯ | закончить запись и сохранить маршрут |
