## 1. Архитектура (коротко)
- Браузерный клиент WoW 3.3.5 (Wow.wasm, Emscripten), сервер AzerothCore. Java 25 + Spring Boot 4.1.2 + Spring AI MCP (stdio),
  Playwright по CDP к отладочному Chrome, PostgreSQL `wow_bot` (пользователь vadim, без пароля).
- Lua → JS: Lua-таблицы с метками ищутся в `wasmMemory` (Float64Array):
  B (777001.5/777002.5; 30 ячеек; `g(i)` в 00-core.js читает `B[i+1]`; B[30] — версия Lua),
  S (777003.5/777004.5; заклинания на панелях, обновление раз в 0.5 с),
  I (777005.5/777006.5; сумки/торговец),
  Q (777009.5/777010.5; 12 ячеек; питомец + цель: exists, hpPct, dead, mend, ttPlayer, ttPet, tBeast).
  ВАЖНО: размер таблицы задаётся конструктором; запись за его пределы перестраивает таблицу в памяти и JS теряет адрес.
- Lua вводится через чат `/run` (≤255 байт), только ASCII, без символа `|`. Загрузчик режет на куски и сжимает пробелы.
  Версия Lua = хеш `lua-setup.txt` (читается ИЗ JAR) + `lua/*.lua`. JS бота читается с диска (`-Dwow.bot-js-dir`),
  поэтому правка JS = `reload_bot`, правка Lua/Java = пересборка + перезапуск (deploy.sh делает игрок).
- Единицы: hpPct/manaPct/maxHpPct — доли 0..1 (в get_state hpPct показывается в %, manaPct — доля).
  Координаты, radius, maxDistance — единицы карты зоны 0..100 (НЕ метры).
- nameHash заклинания: h = (h*31 + байт UTF-8) mod 2147483647 по локализованному (ru) названию.

## 3. Известные баги (по наблюдениям в игре)
1. Автообучение (RotationLearner / EventCollector) перезаписывает ротацию каждые несколько минут и учит:
   Автоматическую стрельбу (75, nameHash 1598442424 — переключатель, повторное нажатие ВЫКЛЮЧАЕТ стрельбу),
   Атаку (6603), Кормление питомца (6991), Лечение питомца (136, 1635767960) без условия, `waitAfter` на автовыстрел.
   Нужно: список исключений по профилю; правила с `maxHpPct`/`maxPetHpPct`/`key`/`repeatMs` сохранять при перезаписи;
   опция «выключить автообучение для профиля». После исправления — убрать закреплённую ротацию hunter из 20-fight.js.
2. `spell_cast.spell_id` всегда NULL — заполнять из spells() по nameHash.
3. `set_rotation` меняет ротацию только в странице, в БД (`rotation_profile`) не сохраняет. Описание инструмента устарело
   (формат `key`/0.35 вместо v2 `spell`/доли). Слабые модели из-за этого шлют неверный формат.
4. Синтетическое нажатие «=» (keyCode 187) игра, похоже, не принимает (Кровавое неистовство не срабатывало).
   Проверить коды Minus/Equal в pressSpell; при необходимости — предупреждать, что клавиша не поддерживается.
5. `remember_vendor` сохранил имя торговца «Утрок» как «урок» (теряется начало кириллицы?).
6. Бот при «стоп/выход» иногда оставляет job в running (проверить все пути выхода).
7. Гринд не садится отдыхать только из-за низкого HP питомца (rest вызывается по HP/мане игрока).
8. Tab выделяет только враждебных (красных); нейтральные жёлтые звери не находятся — нужен скан мышью как запасной путь.
