## MCP-инструмент `hunt` (фоном, как grind)
Параметры (все необязательные): `kills` (по умолчанию 30), `loot` (по умолчанию false), `maxDistance` (по умолчанию 25 единиц карты).
1. get_state → `zone`, `pLvl`, x, y. Найти zone_id в zone_map. Нет записи → ошибка
   «зона N не известна, добавь в zone_map», ничего не делать.
2. Выбрать кластер из mob_cluster: zone_id совпадает, `lvl_max BETWEEN pLvl-4 AND pLvl+1`,
   `lvl_min >= pLvl-5`, не в `empty_until`, расстояние до игрока ≤ maxDistance.
   Оценка: `spawns * (found_rate из hunt_cluster_stat, по умолчанию 1) / (1 + distance/10)`. Брать лучший.
3. `go_to(cx, cy)` (с боем по пути). Если застрял (нет движения > 15 с) — пометить кластер
   `empty_until = now()+60 мин` с причиной «недоступен» и взять следующий.
4. На месте — `grind` mode=radius, **radius = 3** (единицы карты, не метры! допустимо 0.5–10;
   3 ≈ клетка кластера, в Дуротаре 1 ед. ≈ 50 м), с текущими порогами; ограничение по времени:
   если 60 с без новой цели — место «пустое», переход к следующему кластеру.
5. Обновлять hunt_cluster_stat (visits, found, kills).
6. Стоп при достижении `kills`, по `stop`, при смерти (задание 7: autoRevive и продолжить).
7. В get_state в поле grind/hunt показывать: текущий кластер, его мобов, kills, сколько кластеров посещено/пустых.
