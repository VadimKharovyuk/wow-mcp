# Как запускать (памятка)

Все команды — из папки проекта: `cd ~/Downloads/wow-mcp`.

## Что есть и зачем

| Что | Команда | Что делает |
|---|---|---|
| **Всё сразу (обычный запуск)** | `./deploy.sh` | закрывает OpenCode и старый сервер бота, **собирает проект**, запускает Chrome с игрой (если ещё не запущен), открывает OpenCode |
| **Только Chrome с игрой** | команда Chrome из файла `start` (ниже) | Chrome с отладочным портом 9222; зайти в игру персонажем вручную |
| **Telegram-бот без OpenCode** | `./controller.sh` | тот же jar без MCP: Telegram-бот + сбор событий; Ctrl+C — стоп |
| **Дашборд статистики** | `java -jar dashboard/target/wow-dashboard.jar` | страница `http://localhost:8085` (только чтение БД) |

Файл `start` — это просто заметка с командами (не скрипт). Чтобы запустить Chrome отдельно:

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/chrome-wow" \
  --disable-background-timer-throttling \
  --disable-renderer-backgrounding \
  --disable-backgrounding-occluded-windows \
  https://lasthavens.com/play
```

## Обычный день

1. Запустить PostgreSQL (БД `wow_bot`), если не запущен.
2. `./deploy.sh` — соберёт, откроет Chrome и OpenCode. **Открыть НОВУЮ сессию в OpenCode** (иначе не перечитается `AGENTS.md`).
3. Войти в игру персонажем (логин и пароль вводите только вы).
4. В OpenCode или Telegram: «статус», «качайся», «стоп», «команды» — список всех команд.

## Telegram-бот

- Один раз: токен от `@BotFather` и ваш chat id в `telegram.local.properties` (файл не в git).
- Запуск: `./mvnw -q package -DskipTests`, затем `./controller.sh` (лучше в отдельной вкладке терминала). Остановка: Ctrl+C.
- Перезапуск (после правок `telegram.local.properties` или кода): номер процесса каждый раз новый, поэтому
  ```bash
  kill $(pgrep -f "wow.controller=true")
  ./controller.sh
  ```
- Если открыт OpenCode, бот работает и в его процессе — отдельный контроллер не обязателен. Двух ботов не будет: лидером
  (читает события игры и опрашивает Telegram) остаётся тот процесс, который запущен первым.
- Следить: `tail -f logs/wow-mcp.log`. В логе должно быть «Telegram: бот запущен, разрешённых чатов: 1».

## Дашборд статистики

```bash
./mvnw -q -f dashboard/pom.xml package        # сборка (нужна после правок кода дашборда)
java -jar dashboard/target/wow-dashboard.jar   # http://localhost:8085
```
Остановка: Ctrl+C, либо `kill $(lsof -nP -t -iTCP:8085 -sTCP:LISTEN)`.

## После правок кода

| Что менялось | Что сделать |
|---|---|
| `bot/*.js` | в игре «перезагрузи бота» (если в OpenCode задан `-Dwow.bot-js-dir`, пересборка не нужна) |
| Lua (`lua/*.lua`, `lua-setup.txt`) или Java | `./mvnw -q package -DskipTests`, перезапустить сервер (`./deploy.sh` или `./controller.sh`), затем «перезагрузи бота» |
| Дашборд | пересобрать его и перезапустить |

## Остановить всё

- Telegram-контроллер и дашборд: Ctrl+C в их терминалах.
- Сервер бота из OpenCode закрывается вместе с OpenCode (или через `./deploy.sh`, он гасит старый процесс).
- Если процесс «завис» и не отвечает: `pgrep -fl wow-mcp.jar`, затем `kill ПИД`.

## Если что-то не работает

- «Не в мире» / «экран входа» — зайдите в игру персонажем и повторите.
- Бот не подключается к игре — Chrome должен быть запущен с портом 9222 (`curl http://localhost:9222/json/version`).
- Telegram молчит — `curl -m 8 https://api.telegram.org` (нужен интернет/VPN); смотрите `logs/wow-mcp.log`.
- Токен бота в файле `telegram.local.properties`; потеряли или засветили — `/revoke` у `@BotFather`.
