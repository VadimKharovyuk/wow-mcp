# Как запускать (памятка)

Все команды — из папки проекта: `cd ~/Downloads/wow-mcp`.

## Что есть и зачем

| Что | Команда | Что делает |
|---|---|---|
| **Всё сразу (обычный запуск)** | `./deploy.sh` | закрывает OpenCode и старый сервер бота, **собирает проект**, запускает Chrome с игрой (если ещё не запущен), открывает OpenCode |
| **Только Chrome с игрой** | команда Chrome из файла `start` (ниже) | Chrome с отладочным портом 9222; зайти в игру персонажем вручную |
| **Дашборд статистики и разбор журнала** | `./dashboard.sh open` | страница `http://localhost:8085` (только чтение БД): графики, сводка журнала, экспорт JSON, разбор моделью |

Файл `start` — это просто заметка с командами (не скрипт). Чтобы запустить Chrome отдельно:

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/chrome-wow" \
  --disable-background-timer-throttling \
  --disable-renderer-backgrounding \
  --disable-backgrounding-occluded-windows \
  https://lasthavens.com/play
```

## Обычный день

1. Запустить PostgreSQL (БД `wow_bot`), если не запущен.
2. `./deploy.sh` — соберёт, откроет Chrome и OpenCode. **Открыть НОВУЮ сессию в OpenCode** (иначе не перечитается `AGENTS.md`).
3. Войти в игру персонажем (логин и пароль вводите только вы).
4. В OpenCode: «статус», «качайся», «стоп», «команды» — список всех команд.

## Дашборд статистики и разбор журнала

```bash
./dashboard.sh open      # соберёт (если нужно), запустит и откроет страницу http://localhost:8085
./dashboard.sh status    # запущен ли
./dashboard.sh stop      # остановить (только свой процесс)
```
Другой порт: `DASH_PORT=8086 ./dashboard.sh start`. Вручную: `./mvnw -q -f dashboard/pom.xml package`, затем `java -jar dashboard/target/wow-dashboard.jar`.

Блок **«Разбор журнала бота»** внизу страницы (читает таблицу `bot_log`, только чтение):
- **Сводка** — показатели (доли успеха боёв, поиска атакующего, посадки на коня, подхода), тренд по трём частям периода (что исправилось или появилось), проблемы (warn/error), отдельно нормальные события и известный шум (`spell not on bars`).
- **Копировать JSON / Скачать JSON** — те же данные в компактном виде (около 10 КБ): их можно отправить на разбор в чат.
- **Разбор моделью** — отчёт собирает программа, поэтому числа в нём всегда сходятся со сводкой: «Работает», «Что изменилось» (тренд по трём частям периода, провалы в середине), «Значимые проблемы» (повторились ≥ 10 раз или ≥ 10% от числа боёв, плюс ухудшения и низкая эффективность) и «Редкие предупреждения (не проблемы)». Ollama вызывается только если значимые проблемы есть, и пишет лишь гипотезы по ним (модель выбирается в списке, по умолчанию `qwen3.5:9b`, есть `qwen3:8b`; настройки в разделе `analyzer` файла `dashboard/src/main/resources/application.yml`). Нужна запущенная Ollama и скачанная модель; ответ за 30–60 секунд, модель сразу выгружается из памяти. Последний разбор хранится до перезапуска дашборда.

## После правок кода

| Что менялось | Что сделать |
|---|---|
| `bot/*.js` | `./test-js.sh` (проверка синтаксиса и тесты логики без игры, нужен node), затем в игре «перезагрузи бота» (если в OpenCode задан `-Dwow.bot-js-dir`, пересборка не нужна) |
| Lua (`lua/*.lua`, `lua-setup.txt`) или Java | `./mvnw -q package -DskipTests`, перезапустить сервер (`./deploy.sh`), затем «перезагрузи бота» |
| Дашборд | пересобрать его и перезапустить |

## Остановить всё

- Дашборд: Ctrl+C в его терминале.
- Сервер бота из OpenCode закрывается вместе с OpenCode (или через `./deploy.sh`, он гасит старый процесс).
- Если процесс «завис» и не отвечает: `pgrep -fl wow-mcp.jar`, затем `kill ПИД`.

## Если что-то не работает

- «Не в мире» / «экран входа» — зайдите в игру персонажем и повторите.
- Бот не подключается к игре — Chrome должен быть запущен с портом 9222 (`curl http://localhost:9222/json/version`).
