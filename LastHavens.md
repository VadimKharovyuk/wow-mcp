# WoW-бот (LastHavens) — шпаргалка

## 1. Запуск с нуля (каждый раз)

1. **Chrome с игрой** — двойной клик по `~/wow-chrome.command` (или `~/Downloads/wow-mcp/deploy.sh`, он сам запустит Chrome, если его нет).
   Проверка: в этом Chrome открыть `http://localhost:9222/json` — должна быть вкладка `lasthavens.com/play`.
2. **Войти в игру руками** (логин/пароль, персонаж, «Войти в мир»). Бот пароли не вводит никогда.
3. **OpenCode** — открыть, **одно окно**, проект `wow-mcp`, **новая сессия**, **сильная модель** (не бесплатная).
4. В OpenCode: `Перезагрузи бота` → `Покажи состояние`.

> Правило: пока ты на экране входа/выбора персонажа — ничего не пиши боту.

## 2. Команды боту (пишешь в OpenCode обычным текстом)

| Что сказать | Что делает (инструмент) |
|---|---|
| Покажи состояние | координаты, HP, мана, бой, цель, текущая задача (`get_state`) |
| Перезагрузи бота | заново загрузить бота в игру, снять блокировку (`reload_bot`) |
| Пробеги к точке 45, 60 | бег к точке, по пути отбивается (`go_to`) |
| Пробеги к 45, 60 без боя | бег без боя, остановится, если напали (`move_to`) |
| Атакуй цель и дождись конца боя | бой с текущей целью (`fight` + `wait_job`) |
| Собери добычу | лут ближайшего трупа (`loot`) |
| Отдохни | питьё (0) / лечение / отдых до 80% HP (`rest`) |
| Осмотрись и найди цель | скан экрана мышью (`look_around`) |
| Начни гринд: радиус 3, максимум 10 убийств | авто-охота: найти → бой → лут → отдых (`grind`) |
| Стоп | экстренная остановка всего (`stop`) |
| Установи профиль paladin | профиль персонажа для обучения (`set_profile`) |
| Покажи ротацию | текущая/выученная ротация + статистика (`get_rotation`) |
| Переучи ротацию | принудительно переучить по твоей игре (`learn_rotation`) |
| Задай ротацию: … | вручную (`set_rotation`) |
| Начни запись / Останови запись | запись пути и убийств, пока играешь сам (`record_start/stop`) |
| Что ты знаешь о зоне? | где ты/бот убивал мобов (`spots`) |
| *(после 4г)* Покажи заклинания | что на панелях: spellId, слот, клавиша, готовность (`spells`) |

Текущая ручная ротация (раскладка паладина: 1 Правосудие, 3 Длань возмездия, 4 Молот, 7 Свет небес, 8 Бож. защита, 9 Возложение рук, 0 питьё):

Задай ротацию (set_rotation):
[{"key":"9","maxHpPct":0.15},{"key":"4","maxHpPct":0.35},{"key":"7","maxHpPct":0.35,"waitAfter":{"key":"4","ms":1000}},{"key":"8","maxHpPct":0.25},{"key":"3","outOfCombatOnly":true},{"key":"1"}]

## 3. Что делать после изменений

| Что поменялось | Что сделать |
|---|---|
| `src/main/resources/bot/*.js` | только `Перезагрузи бота` |
| `lua-setup.txt` / `lua/*.lua` | `./mvnw -q package -DskipTests` → перезапуск OpenCode со службой → `Перезагрузи бота` *(после 4г с `wow.lua-dir` — только `Перезагрузи бота`)* |
| Java-код | `~/Downloads/wow-mcp/deploy.sh` → новая сессия |
| `~/.config/opencode/opencode.json` | перезапуск OpenCode со службой |

**Перезапуск OpenCode со службой:**
```bash
# Cmd+Q в OpenCode, затем:
pkill -f "opencode-cli serve"; pkill -f wow-mcp.jar
# и открыть OpenCode заново → новая сессия
```

## 4. Терминал: полезные команды

```bash
# Деплой (сборка + перезапуск OpenCode + Chrome при необходимости)
~/Downloads/wow-mcp/deploy.sh

# Сколько серверов бота запущено (норма: 1–2, оба от OpenCode)
ps aux | grep wow-mcp.jar | grep -v grep

# Логи сервера (их два — зависит от папки запуска)
tail -30 ~/Downloads/wow-mcp/logs/wow-mcp.log
tail -30 ~/logs/wow-mcp.log

# Только проблемы
grep -E "ERROR|WARN.*GameBridge|Exception" ~/Downloads/wow-mcp/logs/wow-mcp.log | tail -20

# Видит ли Chrome вкладку игры
curl -s http://localhost:9222/json | grep -c '"url": "https://lasthavens.com/play"'

# База: что накоплено
psql -d wow_bot -c "select source, count(*) from mob_kill group by source"
psql -d wow_bot -c "select key, count(*) from key_press group by key order by key"
psql -d wow_bot -c "select spell_id, count(*) from spell_cast group by spell_id"   # после 4г
```

## 5. Команды в чате игры (проверка)

```
/run print(B and #B, B and B[9], B and B[30])                 -- жива ли таблица бота (не nil = ок)
/run for s=1,12 do local t,id=GetActionInfo(s) print(s,t,t=="spell" and GetSpellName(id,"spell") or id,GetActionTexture(s)) end

/run print(GetSpellInfo(853))                                -- название заклинания по spellId
/reload                                                      -- сбросить интерфейс (потом «Перезагрузи бота»)
```

## 6. Разрешения OpenCode (терминал по запросу)

| Команда модели | Ответ |
|---|---|
| `find`, `ls`, `cat`, `grep`, `head`, `tail` | ✅ Разрешить один раз |
| `./mvnw …`, `node --check` | ✅ Разрешить один раз |
| `java -jar … wow-mcp.jar`, `mcp-client`, всё с `9222` / `curl localhost` | ❌ Запретить |
| `pkill`, `kill`, `deploy.sh`, правка `~/.config/opencode` | ❌ Запретить (это делаешь ты) |
| `rm`, `git reset`, `git checkout` | ⚠️ Сначала прочитать, что удаляется |

«Разрешить всегда» — не нажимать.

## 7. Если что-то не так

| Симптом | Что делать |
|---|---|
| «Персонаж не в мире» | Зайти в мир руками → `Перезагрузи бота` |
| «подготовка заблокирована» | Убедиться, что в мире и чат закрыт → `Перезагрузи бота` |
| «chat did not open» | Кликнуть по портрету персонажа в игре, закрыть открытые окна (Esc) → `Перезагрузи бота` |
| Модель не видит инструменты `wow` | Перезапуск OpenCode со службой → новая сессия → «Какие инструменты wow доступны?» |
| Модель лезет в терминал/браузер, пишет свои скрипты | Остановить (■), сменить модель на сильную, новая сессия |
| Таймауты вызовов | В `opencode.json` должно быть `"timeout":120000` |
| Бот застрял / делает глупости | `Стоп` |
| Персонаж бежит туда, куда кликаешь мышью | Это click-to-move (включён для лута) — так и задумано |

## 8. Важно помнить

- **Одна вкладка игры** и **один вход на аккаунт** (не заходить параллельно с телефона).
- Для обучения ротации играй **в отладочном Chrome**.
- Не ставь умения на **W A S D Q E** — бот ими ходит.
- Пароль от игры в отладочном Chrome лучше не сохранять.
